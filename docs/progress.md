## Roadmap

From v0.1 to v1, the first production release (decision 63). Each step is a phase (decision 69); its spec sections are written before it starts.

| Phase | Version | What it brings |
| --- | --- | --- |
| [6](phases/phase-6-ux-update.md) | v0.2 | UX update: UI in English, Simplified and Traditional Chinese; defaults per story type; previous / next chapter links; tokens per chapter; notes on what each suggested action might do; randomizers for names and matching settings |
| [7](phases/phase-7-look-and-feel.md) | v0.3 | Look and feel: top navigation bar with an About page linking to the itch.io home, chapter side list, new visual style and bookshelf, silhouettes and backgrounds per story type, Fantasy story type, simple animation |
| [8](phases/phase-8-music-and-images.md) | Alpha | Background music by mood; image generation with None, Lite (per chapter) and Rich (per block) |

After phase 8: alpha test with real users, fixes, then v1.

## Later (not planned yet)

- Phone layout and Android build
- Steam packaging and integration
- "Ask the AI" for a new random setting or name, when the curated sets are not enough (phase 6, optional, not built)
- Rewind to an earlier chapter (snapshots are already saved for this)
- Sharing or exporting stories
- An explicit content mode beyond the Mature rating
